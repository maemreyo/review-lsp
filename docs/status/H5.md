## npm dist-tags

Observed after publication:

```text
alpha:  0.1.0-alpha.1
latest: 0.1.0-alpha.1
```

An attempt to delete `latest` returned HTTP 400 from the registry. This is consistent with npm registry package metadata requiring a `latest` dist-tag. Because this is the first and currently only published version, both tags remain on the alpha.

Intentional alpha installation should therefore use:

```bash
npm install review-lsp@alpha
```

The first stable release should move `latest` to the stable version.

## Claim ceiling

The alpha does not claim dependency-snapshot completeness, arbitrary repository support, semantic correctness of the language server, Windows support, JavaScript support, dirty-worktree candidates, remote MCP, signed receipts, or hermetic protection from a malicious container host administrator.

Dependency-bearing projects remain `environment_binding=PARTIAL` until dependency snapshot preparation/admission exists.
