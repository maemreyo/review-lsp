# Code of Conduct

Review-LSP is an open-source engineering project. Contributors, maintainers, and users are expected to interact professionally and constructively.

## Expected behavior

- Be respectful and specific when reviewing ideas or code.
- Critique technical claims, not people.
- Share enough evidence for others to reproduce important claims.
- Respect privacy, confidentiality, and responsible security disclosure.
- Make space for disagreement without harassment, intimidation, or personal attacks.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized conduct, sustained personal attacks, or deliberate disruption are not acceptable in project spaces.

## Enforcement

Maintainers may edit or remove comments, issues, pull requests, or other contributions that violate these expectations, and may temporarily or permanently restrict participation when necessary.

For sensitive conduct reports, use a private contact method listed on the maintainer's GitHub profile. Security vulnerabilities should instead follow [SECURITY.md](SECURITY.md).

This policy applies to repository issues, pull requests, Discussions, and other official Review-LSP project spaces.
